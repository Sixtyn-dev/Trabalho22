03 · Fluxo de conteúdo

CSS Float

A propriedade float desloca uma caixa para a esquerda ou direita, permitindo que texto e conteúdo em linha contornem sua lateral.

Como o Float funciona

Historicamente, float foi muito usado para envolver imagens com texto. Um elemento flutuante sai parcialmente do fluxo normal e o conteúdo ao redor ocupa o espaço disponível.

float: left

Move a caixa para a esquerda, e o texto pode contorná-la pelo lado direito.

float: right

Move a caixa para a direita, e o texto pode contorná-la pelo lado esquerdo.

.imagem {
  float: left;
  margin: 0 16px 10px 0;
}
.limpar {
  clear: both;
}

A propriedade clear evita que um elemento fique ao lado de flutuantes no lado especificado.

Para construir layouts de página modernos, geralmente prefira Flexbox ou Grid. Float continua útil em casos de texto contornando imagens.

Área de testes

Altere o lado da caixa e veja como o texto se reorganiza.

Caixa

Float permite que um texto flua ao redor de um elemento. Experimente mudar a caixa de lado e observe como as linhas de texto ocupam o espaço ao lado dela. Este comportamento é diferente de Flexbox e Grid, que organizam diretamente os itens de um contêiner.
