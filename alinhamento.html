CSS Alinhamento

Alinhar é posicionar elementos horizontal ou verticalmente. A técnica adequada depende do tipo de elemento e do layout utilizado.

Técnicas comuns

Texto

text-align: center centraliza texto e conteúdo inline horizontalmente dentro do bloco.

Margens automáticas

Em um bloco com largura definida, margin-inline: auto pode centralizá-lo horizontalmente.

Flexbox

justify-content alinha no eixo principal e align-items no eixo transversal.

Grid

place-items: center é uma forma curta de centralizar itens nos dois eixos de uma célula/área de Grid.

/* Centralizar um bloco */
.bloco {
  width: min(100%, 320px);
  margin-inline: auto;
}

/* Centralizar conteúdo com Flexbox */
.pai {
  display: flex;
  justify-content: center;
  align-items: center;
}
