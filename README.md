# Hub de Estudos CSS — Flexbox e Grid

Projeto educacional estático feito com HTML, CSS e JavaScript puro para estudar seis tópicos de layout:

1. **Box Model** — conteúdo, padding, borda e margem.
2. **Position** — static, relative, absolute, fixed e sticky.
3. **Float** — elementos flutuantes e limpeza de fluxo.
4. **Alinhamento** — texto, margens, Flexbox e Grid.
5. **Flexbox** — layout unidimensional, eixos, alinhamento, quebra e propriedades flexíveis.
6. **CSS Grid** — linhas, colunas, frações, áreas e layouts responsivos.

## Estrutura

- `index.html` / `index.css` — página inicial do hub.
- `style.css` — estilo compartilhado pelas páginas de conteúdo.
- `box-model.html`
- `position.html`
- `float.html`
- `alinhamento.html`
- `flexbox.html`
- `grid.html`
