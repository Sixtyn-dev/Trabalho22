# Hub de Estudos CSS — Flexbox e Grid

Projeto educacional estático feito com HTML, CSS e JavaScript puro para estudar seis tópicos de layout:

1. **Box Model** — conteúdo, padding, borda e margem.
2. **Position** — static, relative, absolute, fixed e sticky.
3. **Float** — elementos flutuantes e limpeza de fluxo.
4. **Alinhamento** — texto, margens, Flexbox e Grid.
5. **Flexbox** — layout unidimensional, eixos, alinhamento, quebra e propriedades flexíveis.
6. **CSS Grid** — linhas, colunas, frações, áreas e layouts responsivos.

## Como abrir localmente

Baixe ou extraia os arquivos e abra `index.html` no navegador. Não precisa instalar dependências ou executar um servidor.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie **todos os arquivos desta pasta** para a raiz do repositório (incluindo `index.html`, CSS e as seis páginas).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação e abra a URL que o GitHub Pages mostrar na tela de configurações.

O arquivo `index.html` está na raiz, como esperado para publicação a partir da raiz do repositório.

## Estrutura

- `index.html` / `index.css` — página inicial do hub.
- `style.css` — estilo compartilhado pelas páginas de conteúdo.
- `box-model.html`
- `position.html`
- `float.html`
- `alinhamento.html`
- `flexbox.html`
- `grid.html`

## Observação

Este pacote é um projeto completo e independente que segue a proposta visual de um hub didático. Para a entrega acadêmica, publique os arquivos no **seu próprio repositório** e envie o link do repositório e, se solicitado, o link público do GitHub Pages.
