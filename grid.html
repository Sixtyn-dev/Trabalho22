06 · Layout bidimensional

CSS Grid

CSS Grid é um sistema de layout bidimensional. Ele organiza os elementos em linhas e colunas, permitindo controlar a estrutura geral da página e o espaço entre as áreas.

1. Contêiner, linhas e colunas

Para ativar o Grid, use display: grid. Depois, defina as colunas com grid-template-columns e as linhas, se necessário, com grid-template-rows.

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 12px;
}

A unidade fr representa uma fração do espaço disponível. Três colunas 1fr 1fr 1fr dividem o espaço livre em três partes iguais.

Coluna 1│Coluna 2│Coluna 3
Linha 1→Linha 2

2. Propriedades principais

PropriedadeFunção
grid-template-columnsDefine número e tamanho das colunas.
grid-template-rowsDefine número e tamanho das linhas explícitas.
gapDefine o espaço entre linhas e colunas.
grid-columnDefine em quais linhas de grade um item começa e termina horizontalmente.
grid-rowDefine em quais linhas de grade um item começa e termina verticalmente.
grid-template-areasPermite nomear áreas e mapear a estrutura visual.
justify-itemsAlinha itens dentro de suas células no eixo inline.
align-itemsAlinha itens dentro de suas células no eixo de bloco.

3. Layout responsivo

Uma combinação útil para cartões é repeat com minmax e auto-fit. O navegador cria quantas colunas couberem, respeitando a largura mínima definida.

.cards {
  display: grid;
  grid-template-columns: repeat(
    auto-fit,
    minmax(220px, 1fr)
  );
  gap: 16px;
}
Flexbox é ótimo quando você organiza itens em uma dimensão. Grid é especialmente útil quando precisa controlar linhas e colunas ao mesmo tempo. Os dois podem ser usados juntos.

5. Posicionando itens

Um item pode ocupar mais de uma coluna ou linha usando linhas numeradas da grade.

.destaque {
  grid-column: 1 / 3; /* ocupa da linha 1 até a 3 */
  grid-row: 1 / 2;
}

Também é possível criar um layout por áreas nomeadas, o que torna a estrutura mais fácil de ler e manter.

.pagina {
  display: grid;
  grid-template-areas:
    "topo topo"
    "menu conteudo"
    "rodape rodape";
  grid-template-columns: 220px 1fr;
  gap: 16px;
}
