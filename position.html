CSS Position

A propriedade position define como um elemento é posicionado no documento e como propriedades como top, right, bottom e left atuam.

Os principais valores

static

Valor padrão. O elemento segue o fluxo normal; offsets não o deslocam.

relative

Permanece no fluxo, mas pode ser deslocado a partir de sua posição original. Também pode servir de referência para um descendente absolute.

absolute

Sai do fluxo normal e se posiciona em relação ao ancestral posicionado mais próximo.

fixed

Fica preso à janela de visualização, mesmo quando a página rola.

sticky

Comporta-se como relativo até atingir um limite de rolagem, quando passa a ficar preso.

Exemplo de código

.pai {
  position: relative;
  min-height: 180px;
}
.filho {
  position: absolute;
  top: 12px;
  right: 12px;
}

O elemento com position: relative cria um contexto de posicionamento. O filho absoluto será alinhado ao canto superior direito desse pai.

Atenção: absolute e fixed normalmente saem do fluxo, então outros elementos não reservam espaço para eles.
