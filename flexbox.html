05 · Layout unidimensional

CSS Flexbox

Flexbox é um modelo de layout para distribuir e alinhar itens em uma dimensão por vez: uma linha ou uma coluna. É muito útil para menus, barras, grupos de botões e componentes responsivos.

1. Contêiner e itens

O elemento pai vira um contêiner flexível com display: flex. Seus filhos diretos tornam-se itens flexíveis. Por padrão, os itens ficam em uma linha.

.container {
  display: flex;
  gap: 12px;
}

O contêiner controla a organização do conjunto; propriedades como flex-grow e align-self podem afetar cada item.

2. Os dois eixos

Eixo principal

É a direção definida por flex-direction. Pode ser horizontal com row ou vertical com column.

Eixo transversal

É perpendicular ao principal. Em uma linha, costuma ser vertical; em uma coluna, costuma ser horizontal.

justify-content distribui espaço no eixo principal. align-items alinha itens no eixo transversal. A direção dos eixos muda quando a direção do Flexbox muda.

3. Propriedades importantes

PropriedadePara que serve
flex-directionDefine linha ou coluna e sua ordem.
justify-contentDistribui itens no eixo principal.
align-itemsAlinha os itens no eixo transversal.
flex-wrapPermite que itens quebrem para outra linha/coluna.
align-contentDistribui linhas/colunas quando há espaço transversal extra e múltiplas linhas.
gapDefine o espaço entre itens e linhas sem usar margens.
flex-growDefine quanto um item pode crescer para ocupar espaço livre.
flex-shrinkDefine como um item encolhe quando falta espaço.
flex-basisDefine o tamanho inicial de um item no eixo principal.
align-selfPermite sobrescrever o alinhamento transversal de um item específico.

5. Um pouco mais: flex

A forma abreviada flex combina crescimento, encolhimento e tamanho-base. Por exemplo, flex: 1 costuma permitir que os itens compartilhem o espaço disponível de maneira flexível.

.item {
  flex: 1 1 180px;
}
/* grow: 1 | shrink: 1 | basis: 180px */

Esse padrão é útil para cartões que tentam ter uma largura mínima aproximada e quebram para a linha seguinte quando necessário.
