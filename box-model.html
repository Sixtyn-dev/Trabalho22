CSS Box Model

Todo elemento HTML pode ser entendido como uma caixa. O Box Model explica como o conteúdo, o espaçamento interno, a borda e a margem ocupam espaço na página.

As quatro partes da caixa

Margin→Border→Padding→Content

Content

Área em que fica o texto, a imagem ou outro conteúdo. Controlada por width e height.

Padding

Espaço interno entre o conteúdo e a borda. Aumenta a área interna da caixa.

Border

Contorno da caixa, definido com propriedades como border e border-radius.

Margin

Espaço externo que separa a caixa de outros elementos.

Como o tamanho é calculado?

Com o valor padrão content-box, a largura total soma conteúdo, padding e bordas. A margem fica fora dessa largura.

.caixa {
  width: 200px;
  padding: 20px;
  border: 5px solid #55e6ef;
  margin: 10px;
}
/* largura da caixa sem margem: 200 + 40 + 10 = 250px */

Com box-sizing: border-box, a largura declarada já inclui conteúdo, padding e borda, facilitando a criação de layouts previsíveis.

* {
  box-sizing: border-box;
}
Boa prática: usar box-sizing: border-box globalmente evita cálculos inesperados de largura.
